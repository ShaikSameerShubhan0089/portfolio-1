Case 01 · Geospatial AI · 2026

Prototype

CarbonSphere AI

Satellite imagery in, auditable forest-carbon estimates out.

Problem
Forest carbon audits rely on manual tree counting — slow, expensive, outdated on delivery.
Built
A FastAPI pipeline: Sentinel-2 NDVI → OpenCV canopy segmentation → GIS area → IPCC Tier 1 biomass-to-CO₂.
Impact
One POST /forest/analyze call returns biomass, CO₂e and carbon-credit estimates, stored for audit.

Python · FastAPI · Google Earth Engine · OpenCV · MongoDB

RISE — Autism Risk Detection

Case 03 · Database AI agents · 2025

Prototype

QueryVault AI

Four LLM agents that read a slow query’s plan and tell you how to fix it.

Problem
Slow SQL is hard to fix — reading EXPLAIN plans and choosing indexes takes database expertise most developers don’t have.
Built
A FastAPI service that feeds a query’s schema, EXPLAIN plan and sample rows to four LLM agents — Query Optimizer, Cost Advisor, Schema Advisor and Data Validator.
Impact
One /analyze call returns a rewritten query, index and cost recommendations, warnings and the plan — and only read-only SELECT/WITH queries are allowed to run.

Python · FastAPI · Groq (Llama 3.3 70B) · MariaDB · aiomysql
