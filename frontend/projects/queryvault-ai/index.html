QueryVault AI

Four LLM agents analyze a slow SQL query and suggest ways to improve it.

01 · The problem

What this project addresses

Interpreting SQL EXPLAIN plans and choosing indexes can require database expertise that many application developers do not have.

02 · Implementation

How it works

A FastAPI service uses an async MariaDB client to collect schemas, an EXPLAIN plan, and up to five sample rows. Four Groq-hosted agents—Query Optimizer, Cost Advisor, Schema Advisor, and Data Validator—return structured recommendations. The API rejects data-changing and schema-changing SQL; only SELECT and WITH queries are allowed.

03 · Outcome

What it does

One /analyze request returns a rewritten query, index and cost recommendations, warnings, the plan, and sample rows. The prototype also provides a schema overview endpoint for its interface.
