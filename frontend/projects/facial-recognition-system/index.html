Facial Recognition System

A webcam application for live face detection and recognition.

01 · The problem

What this project addresses

A webcam identity-check prototype needs to detect faces quickly and match them against captured examples.

02 · Implementation

How it works

OpenCV captures webcam frames, a Haar Cascade detects faces, and an LBPH recognizer trained on captured faces identifies known faces.

03 · Outcome

What it does

The prototype displays recognition feedback for known faces in a live webcam feed. It is not deployed publicly; source code is available in the repository.

Technologies

  • Python
  • OpenCV
  • Haar Cascade
  • LBPH
