Movie Recommender System

A content-similarity recommender that returns five films similar to a selected movie.

01 · The problem

What this project addresses

Choosing what to watch next from a large catalog can be difficult when a viewer has a particular film in mind.

02 · Implementation

How it works

The project applies content similarity to the TMDB 5000 dataset and presents the recommendations through a Streamlit interface.

03 · Outcome

What it does

A user selects a movie and receives five similar titles.

Technologies

  • Python
  • scikit-learn
  • Streamlit
  • TMDB 5000 dataset
