Shaik Sameer Portfolio

A personal portfolio with a gated résumé request flow and the Laddu AI assistant.

01 · The problem

What this project addresses

The site needed a résumé request process that lets Sameer approve delivery, plus a way for visitors to ask follow-up questions about his work.

02 · Implementation

How it works

Résumé requests produce a signed, expiring approval link, followed by a confirmation step to prevent email link scanners from triggering delivery. Email uses Brevo with a Gmail SMTP fallback. Laddu answers from a curated fact sheet, has short conversation memory, and supports voice input and spoken replies. Both API endpoints are rate-limited.

03 · Outcome

What it does

Résumé delivery requires approval, and visitors can ask typed or spoken questions about the portfolio. The Flask backend and static frontend are deployed separately.
