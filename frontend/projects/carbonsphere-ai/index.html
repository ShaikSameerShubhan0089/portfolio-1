CarbonSphere AI

Satellite imagery in, auditable forest-carbon estimates out.

01 · The problem

What this project addresses

Forest carbon audits rely on manual plot sampling and physical tree counts. That work is expensive, takes weeks per report, and can be out of date as soon as it is delivered.

02 · Implementation

How it works

A FastAPI service combines Sentinel-2 NDVI from Google Earth Engine, OpenCV HSV canopy segmentation, GIS area calculation, and an IPCC Tier 1 biomass-to-CO₂ model. Analyses are saved in MongoDB for auditability, with a Leaflet and Chart.js dashboard for maps and trends.

03 · Outcome

What it does

A POST /forest/analyze request turns coordinates and an image into biomass, carbon-stock, CO₂-equivalent, and carbon-credit estimates, with stored history for review. This is a prototype.

Technologies

  • Python
  • FastAPI
  • Google Earth Engine
  • OpenCV
  • MongoDB
  • Leaflet
