Portfolio Generator

A portfolio builder for creating responsive, customizable portfolio websites.

01 · The problem

What this project addresses

Creating a presentable personal portfolio from scratch takes time and web-development experience.

02 · Implementation

How it works

The application combines JWT registration, login and password reset; six responsive templates; a live-preview builder; and image and résumé uploads. Nodemailer handles reset and sharing emails, while the interface is designed for mobile screens and touch input.

03 · Outcome

What it does

Users can fill in profile and project details, preview a template, and publish a portfolio without starting with a blank codebase.

Technologies

  • Node.js
  • Express
  • React
  • MongoDB
  • JWT
  • Multer
  • Nodemailer
