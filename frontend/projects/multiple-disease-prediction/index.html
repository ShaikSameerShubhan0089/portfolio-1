Multiple Disease Prediction

A Streamlit application with five disease-risk screening models.

01 · The problem

What this project addresses

Early warning for common conditions can benefit from accessible screening using routine health inputs.

02 · Implementation

How it works

The application brings together Random Forest models for diabetes, heart disease, Parkinson’s disease, lung cancer, and hypothyroidism. Each condition has its own inputs, example values, and explanations of the measurements.

03 · Outcome

What it does

A single Streamlit app provides five separate screening flows. Its predictions are screening outputs and are not a medical diagnosis.

Technologies

  • Python
  • scikit-learn
  • Streamlit
